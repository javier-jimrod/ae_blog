---

{: style="text-align: justify"}
An AutoEncoder [^1] is a type of artificial neural network [^2] whose goal is to reconstruct its input while learning an efficient representation of it.
These neural networks are trained unsupervisedly [^3] and are able to learn compressed representations of input patterns to then reconstruct them.

{: style="text-align: justify"}
Typically, AutoEncoders can be divided in two submodels: the *encoder* and the *decoder*.
The encoder transforms the input data into a compressed, lower-dimensional representation, while the decoder reconstructs the original input from this compressed representation.

{: style="text-align: justify"}
AutoEncoders come in different flavours ranging from the vanilla architecture, the simplest basic form of AutoEncoder shown above, to more complex models [^4] appropriate for different contexts.
For example, Undercomplete AutoEncoders are suitable for dimensionality reduction tasks, such as feature extraction, by forcing the network to compress the input into a lower-dimensional space. Sparse AutoEncoders, on the other hand, use regularization to promote sparsity in the encoded representations, which can enhance interpretability by highlighting only the most important features of the data.

{: style="text-align: justify"}
In essence, AutoEncoders serve as a versatile tool in the machine learning toolbox, with each variant suited for specific applications like data denoising, anomaly detection, or dimensionality reduction.
